# First-Choice Cyber — Website

Marketing website for First-Choice Cyber, a customer reactivation and AI governance firm serving healthcare, construction, energy, and other regulated industries.

## About

This site is deployed at [firstchoicecyber.com](https://firstchoicecyber.com) and serves as the primary lead generation and booking platform for First-Choice Cyber.

## Local Development

**Requirements:** Node.js 18+

```sh
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## Deployment

The site is deployed on Netlify with automatic branch deploys. A `_redirects` file handles SPA routing so all routes resolve correctly.

## Pages

- `/` — Main landing page
- `/resources` — Resources and lead magnet page
